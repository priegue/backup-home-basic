# 🔄 Backup Home Basic
Script en Shell para automatizar la copia de seguridad del directorio HOME del usuario, generando archivos 
comprimidos y registros de ejecución.

🌎 Idiomas:
- 🇧🇷 Português: ../README.md
- 🇺🇸 English: README-en.md
- 🇪🇸 Español (actual)

------------------------------------------------------------

## 📌 Sobre el proyecto
Este proyecto crea automáticamente una copia de seguridad del directorio HOME del usuario, generando un 
archivo .tar.gz con fecha y hora, además de guardar registros en un archivo de log para auditoría.

Excelente para principiantes en:
- Linux  
- Shell Script  
- Automatización de backups  
- Prácticas básicas de DevOps

------------------------------------------------------------

## 🛠 Tecnologías utilizadas
- Linux  
- Shell Script  
- Compresión tar  
- Sistema de logs  
- Estructura de directorios para proyectos reales

------------------------------------------------------------

## ▶️ Cómo ejecutar

1) Dar permiso de ejecución al script:
   chmod +x backup.sh

2) Ejecutar el backup:
   ./backup.sh

El archivo generado tendrá el formato:
   backup-YYYY-MM-DD_HH-MM.tar.gz

Los registros de ejecución se guardan en:
   logs/backup.log
