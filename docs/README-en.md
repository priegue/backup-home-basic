# 🔄 Backup Home Basic
Shell Script to automate the backup of the user's HOME directory, generating compressed files and execution 
logs.

🌎 Languages:
- 🇧🇷 Português: ../README.md
- 🇺🇸 English (current)
- 🇪🇸 Español: README-es.md

------------------------------------------------------------

## 📌 About the project
This project automatically creates a backup of the user's HOME directory, generating a .tar.gz file with 
timestamp and saving log records for auditing.

Great for beginners in:
- Linux
- Shell Script
- Backup automation
- Basic DevOps practices

------------------------------------------------------------

## 🛠 Technologies used
- Linux
- Shell Script
- tar (compression)
- Log management
- Basic directory structure for real projects

------------------------------------------------------------

## ▶️ How to run

1) Make the script executable:
   chmod +x backup.sh

2) Run the backup:
   ./backup.sh

The generated file will follow the format:
   backup-YYYY-MM-DD_HH-MM.tar.gz

Log records will be stored in:
   logs/backup.log
